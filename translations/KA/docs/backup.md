# სარეზერვო ასლების ჩატვირთვა
სამწუხაროდ, შენახული თამაში ზოგჯერ შეიძლება დაზიანდეს, ან კოდის რომელიმე ფაილი დაიკარგოს. ასეთ დროს შეგიძლია სცადო სარეზერვო ასლის ჩატვირთვა. თუ ეს ხშირად ხდება, სცადე Steam Cloud-ის გამორთვა.

სარეზერვო ასლი იქმნება ყოველ ჯერზე, როცა თამაში ინახება, და რამდენიმე ასლი რჩება იმ შემთხვევისთვის, თუ რამის აღდგენა დაგჭირდა.
ამ ასლებს [სარეზერვო ასლების საქაღალდეში](persistent_data_path/Backup) იპოვი. ისინი [შენახვების საქაღალდეში](persistent_data_path/Saves) არსებული შენახული თამაშების ასლებია.
სარეზერვო ასლის ჩატვირთვის ყველაზე მარტივი გზაა, სასურველი ასლის საქაღალდე შენახვების საქაღალდეში გადააკოპირო.

შენახული თამაში არის საქაღალდე, რომელშიც დევს `save.json` ფაილი და ბევრი `.py` ფაილი.
თუ მხოლოდ რამდენიმე კოდის ფაილი დაკარგე, ან კოდის ფაილები ისევ ადგილზეა, მაგრამ `save.json` ფაილია დაზიანებული, შეგიძლია მხოლოდ დაზიანებული ნაწილები შეცვალო სარეზერვო ასლის შესაბამისი ფაილებით.
