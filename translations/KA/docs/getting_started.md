# პირველი ნაბიჯები
ამ ფანჯარაში თამაშის ყველა საკითხზე იპოვი ინფორმაციას.

ფანჯრების გადაადგილება შეგიძლია, თუ ფანჯრის ნაცრისფერ ნაწილს გადაათრევ.
კამერის გადასაადგილებლად გადაათრიე ფანჯრების გარეთ ნებისმიერ ადგილას.

პროგრამირების დასაწყებად გადადი გვერდზე [პირველი პროგრამა](docs/first_program.md) ბმულზე დაწკაპუნებით.

აუცილებლად ნახე ღილაკები ეკრანის ზედა მარჯვენა კუთხეში. თუ მაუსს მათზე მიიტან, გამოჩნდება მინიშნება, რომელიც გეტყვის, რას აკეთებს თითოეული. ერთ-ერთი მათგანი ტექნოლოგიების ხეს ხსნის!
