# პირველი პროგრამა
## ტექსტური რედაქტორი
მთელი პროგრამირება კოდის ფანჯრებში ხდება. თითოეული კოდის ფანჯარა შეესაბამება ტექსტურ ფაილს, რომელშიც კოდი წერია. 
ფაილს სახელის გადარქმევა შეგიძლია, თუ ფანჯრის ზედა ნაწილში მის სახელზე დააწკაპუნებ.

კოდის რედაქტირება ისევე შეგიძლია, როგორც ნებისმიერ ტექსტურ რედაქტორში, ოღონდ მხოლოდ მაშინ, როცა ის არ სრულდება.
პროგრამის პირდაპირ გაშვება შეგიძლია კოდის ფანჯარაში მწვანე გაშვების ღილაკზე დაჭერით.
![|x50](PlayButton)

ახალი კოდის ფაილების შექმნა შეგიძლია ეკრანის ზედა მარჯვენა კუთხეში არსებული "+" ღილაკით.
ფანჯრის სხვა ფანჯარაზე მიმაგრება შეგიძლია, თუ ერთს მეორეზე გადაათრევ.

როგორც კი წერას დაიწყებ, დაინახავ, რომ ავტოდასრულების პატარა ფანჯარა ამოხტება.
არჩეული ვარიანტის ჩასასმელად დააჭირე Tab-ს.
ვარიანტებს შორის გადასაადგილებლად ისრიანი კლავიშები გამოიყენე.

ნუ ინერვიულებ, თუ პროგრამირებას პირველად ცდილობ. ენის შესაძლებლობები ნაბიჯ-ნაბიჯ განიბლოკება, ამიტომ ყველაფერი ერთბაშად თავზე არ დაგატყდება. 
სინტაქსი Python-საც ჰგავს. ეს მსოფლიოში ერთ-ერთი ყველაზე გავრცელებული პროგრამირების ენაა, ამიტომ რასაც აქ ისწავლი, სხვაგანაც გამოგადგება.

თუ Python უკვე იცი, ესეც კარგია: თამაშის დასაწყისს სწრაფად გაივლი და უფრო საინტერესო რამეებს მალე მიადგები.

ამჟამად დრონის ორი ბრძანება გაქვს ხელმისაწვდომი.

`harvest()`

და 

`do_a_flip()`

ეს ფუნქციების გამოძახებებია. ფუნქცია შეგიძლია წარმოიდგინო როგორც ბრძანება, რომლის შესრულებაც შეიძლება. `()` ფრჩხილები ასრულებს მას.

სცადე, ეს ინსტრუქციები კოდის ფანჯარაში ჩაწერო და შესრულების ღილაკს დააჭირო.

შეგიძლია წარმოიდგინო, რომ შენი კოდი ინსტრუქციების მიმდევრობაა. რამდენიმე ინსტრუქციის ზედიზედ შესასრულებლად ისინი სხვადასხვა ხაზზე დაწერე.

## განბლოკვები
