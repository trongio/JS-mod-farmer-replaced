# გარე რედაქტორი
თამაშის შიგნით არსებული ტექსტური რედაქტორი სათამაშოდ ჩვეულებრივ სავსებით საკმარისია, მაგრამ, რა თქმა უნდა, ვერ შეედრება ისეთ უფრო დახვეწილ რედაქტორებს, როგორიცაა Visual Studio Code.

თამაში კოდის ყველა ფაილს .py ფაილად ინახავს, ამიტომ მათი რედაქტირება Python-ის რედაქტორებითაც შეგიძლია. 
გაითვალისწინე, რომ ეს მხოლოდ მოხერხებულობისთვისაა. თამაშის ენა სინამდვილეში Python არ არის, მაგრამ იმდენად ახლოსაა მასთან, რომ Python-ის IntelliSense მასზე საკმაოდ კარგად მუშაობს.
ფაილებს [შენახვების საქაღალდეში](persistent_data_path/Saves) იპოვი.

მუდმივი მონაცემების საქაღალდე აქ მდებარეობს:

- Windows: `%USERPROFILE%\AppData\LocalLow\TheFarmerWasReplaced\TheFarmerWasReplaced`
- macOS: `~/Library/Application Support/com.TheFarmerWasReplaced.TheFarmerWasReplaced`
- Linux (Steam/Proton): `~/.steam/steam/steamapps/compatdata/2060160/pfx/drive_c/users/steamuser/AppData/LocalLow/TheFarmerWasReplaced/TheFarmerWasReplaced`

ყოველ შენახულ თამაშში ასევე არის `__builtins__.py` ფაილი, რომელშიც Python-ის ჩაშენებული განსაზღვრებებია. ისინი თამაშის ჩაშენებულ ელემენტებს შეესაბამება და IntelliSense-ს ამუშავებს. 
VS Code `__builtins__.py`-ს ავტომატურად პოულობს, მაგრამ ზოგიერთი რედაქტორი შეიძლება მხოლოდ მაშინ იმუშაოს, თუ დაამატებ `from __builtins__ import *`-ს.

გარე ცვლილებები რომ თამაშში ისე დაინახო, რომ შენახული თამაშის თავიდან ჩატვირთვა არ დაგჭირდეს, უნდა ჩართო პარამეტრი "ფაილების თვალყურის დევნება". თუ ფაილებს თამაშის გარეთ შექმნი ან წაშლი, მათ დასანახად შენახული თამაშის თავიდან ჩატვირთვა მაინც დაგჭირდება.

## VS Code-ის გამოყენება
The Farmer Was Replaced-თან სამუშაოდ რეკომენდებული კოდის რედაქტორი Visual Studio Code არის.

მისი დაყენება [აქ](https://code.visualstudio.com/download) შეგიძლია.

ჩამოტვირთვის შემდეგ VS Code-ში Python-ის გაფართოება დააყენე.

ამის შემდეგ VS Code-ში გახსენი [საქაღალდე](persistent_data_path/Saves), სადაც შენი `.py` ფაილებია. აუცილებლად მთელი საქაღალდე გახსენი და არა ცალკეული ფაილები, თორემ `__builtins__.py` ფაილი არ იმუშავებს.

თამაშში დარწმუნდი, რომ პარამეტრი "ფაილების თვალყურის დევნება" ჩართული გაქვს. ახლა, როცა კი VS Code-ში შეინახავ, ცვლილებები თამაშში ავტომატურად გამოჩნდება.

სულ ეს არის! ახლა შეგიძლია კოდი პროფესიონალურ რედაქტორში წერო!
