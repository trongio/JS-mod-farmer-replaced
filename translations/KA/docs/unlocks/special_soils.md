# პერლიტი და თიხნარი
ეს განბლოკვა მიწისქვეშა ბლოკების ორ ახალ ტიპს ამატებს: პერლიტსა და თიხნარს (`Grounds.Perlite` და `Grounds.Loam`). როცა ამ ნიადაგებზე დარგულ მცენარეებს მოკრეფ, ორმაგ მოსავალს მიიღებ.

პერლიტი და თიხნარი მიწისქვეშ თხელ ფენებად გვხვდება, თიხის მსგავსად, მაგრამ ცოტა უფრო იშვიათია.

პერლიტი ჰაეროვანი ნიადაგების მოყვარული მცენარეებისთვისაა: კაქტუსების, ბამბუკის, ბუჩქებისა და ხეებისთვის. პერლიტზე დარგული ეს მცენარეები ჩვეულებრივზე ორჯერ მეტ მოსავალს იძლევა.

თიხნარი სტაფილოსა და მზესუმზირებისთვისაა. თიხნარზე დარგული ეს მცენარეები ორჯერ მეტ მოსავალს იძლევა.

პერლიტისა და თიხნარის კიდევ ერთი უპირატესობა ისაა, რომ დასარგავად მაშინვე მზადაა, `Grounds.Grassland`-ისგან განსხვავებით, რომელიც ჯერ `till()`-ით უნდა გადახნა და `Grounds.Soil`-ად აქციო.
