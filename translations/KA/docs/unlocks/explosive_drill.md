# ფეთქებადი ბურღი
ფეთქებადი ბურღი `change_hat(Hats.Explosive_Drill)`-ით გაიკეთე.

სანამ ფეთქებადი ბურღი გაკეთებული გაქვს, `dig()`-ის გამოძახება ერთ `Items.Dynamite`-ს ხარჯავს და აფეთქებას იწვევს, რომელიც `use_item(Items.Dynamite)`-ის აფეთქებას ჰგავს. ოღონდ ჩვეულებრივი დინამიტის აფეთქებისგან განსხვავებით, ის აფეთქების არეში მოხვედრილ ყველა ბლოკს აგროვებს!

ფეთქებადი ბურღი მხოლოდ ერთი გაქვს, ამიტომ ერთდროულად მხოლოდ ერთ დრონს შეუძლია მისი გაკეთება.
