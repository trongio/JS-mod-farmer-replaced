# სამთო საქმე
შენს დრონს მარტივი ბურღი ერგო, რომლითაც მიწისქვეშეთში განძების ძებნა შეუძლია.

ბლოკზე მაუსის მიტანისას გამოჩნდება მისი სახელი, მდგრადობა და სიმაგრე.

# ბურღი
რაც უფრო ღრმად თხრი, შეამჩნევ, რომ ბლოკები უფრო მაგარი ხდება და თხრას მეტი დრო სჭირდება. კარგია, რომ ბურღის გაუმჯობესება შეგვიძლია!

იმისთვის, რომ დრონი მიწისქვეშეთში უკეთ გაერკვეს, მალე განბლოკე [მიწისქვეშა გრძნობები](docs/unlocks/underground_senses.md). ამით ის შეძლებს საკუთარი z-პოზიციის, ქვემოთ მყოფი მიწის ტიპის, მისი სიმაგრისა და მდგრადობის შემოწმებას.

მაგალითად, [მიწისქვეშა გრძნობებით](docs/unlocks/underground_senses.md) შეგიძლია `get_hardness()`-ით შეამოწმო შენს ქვეშ მყოფი ბლოკის სიმაგრე. თუ განსაკუთრებით მაგარ ბლოკებს გადაეყარე, შეიძლება ჯობდეს გვერდი აუარო, რომ უფრო სწრაფად წახვიდე წინ:

`while True:
    if get_hardness() < 5:
        dig()
    else:
        move(East)`

რა თქმა უნდა, რაც უფრო ქვემოთ ჩადიხარ, ბლოკები მით უფრო მაგარი ხდება, ამიტომ ეს სტრატეგია გეხმარება, მაგრამ დიდხანს ვერ გაგიტანს.

## ჩამონგრევები
ქვემოთ თხრისას გარშემო ბლოკები ინგრევა. დრონის გვერდით მყოფი ოთხი ბლოკი ყოველთვის ნადგურდება. ამის შემდეგ ჩამონგრევა მიწის მდგრადობის მიხედვით ვრცელდება. 1 მდგრადობის ბლოკს, მაგალითად ბალახნარს, 1-ის ტოლი სიმაღლის სხვაობის გაძლება შეუძლია. სხვა სიტყვებით, თუ ბალახნარს აქვს ვერტიკალური ან ჰორიზონტალური მეზობელი, რომლის z-კოორდინატი 2 ან მეტი ბლოკით უფრო ღრმაა, ბალახნარი განადგურდება.

ბლოკის მდგრადობა ნაჩვენებია მინიშნებაში, რომელიც მასზე მაუსის მიტანისას ჩნდება.

როცა ბლოკი ინგრევა, ის თავის ზემოთ მყოფ ყველა ბლოკსაც აშორებს. რესურსებს მხოლოდ იმ ბლოკებიდან იღებ, რომლებსაც დრონი პირდაპირ თხრის, ამიტომ ჩამონგრევისას დაკარგული ბლოკები რესურსის გარეშე ნადგურდება.
