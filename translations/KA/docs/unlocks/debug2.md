# გამართვა 2
როცა დრონი ზედმეტად სწრაფი ხდება, ბადე კი ზედმეტად დიდი, შეიძლება გაგიჭირდეს იმის დანახვა, რა ხდება.

ამიტომ შეგიძლია გამოიყენო `set_execution_speed()` და `set_world_size()` ფუნქციები.
ისინი შესრულების სიჩქარესა და ფერმის ზომას ამცირებს.

შესრულების დასრულებისას ფერმის ზომა და შესრულების სიჩქარე ნაგულისხმევ მნიშვნელობებს დაუბრუნდება.
