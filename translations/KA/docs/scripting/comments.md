# კომენტარები
კომენტარები კოდის ის ნაწილებია, რომლებიც შესრულებისას იგნორირდება.
კომენტარის დამატება `#`-ით შეგიძლია. ყველაფერი, რაც იმავე ხაზზე `#`-ის შემდეგ წერია, კომენტარია და იგნორირდება.

{{codeexample 
{
    "show_image": false,
    "show_code": true,
    "show_inventory": false,
    "show_output": true,
    "collapsing": true,
    "autoplay": false,
    "execution_speed": 1,
    "digging_speed": 1,
    "action_ticks": 200,
    "operation_ticks": 100,
    "seed": 0,
    "exclude_unlocks": ["watering", "fertilizer"],
    "starting_chunk": 0,
    "dlc_enabled": false
}
#SETUP
#CODE
#this is a comment
#harvest()
}}

ეს გამოგადგება, თუ კოდში შენიშვნების დამატება გინდა, ან მისი ნაწილების დროებით გამორთვა ისე, რომ არ წაშალო.

ფუნქციის განსაზღვრების წინა ხაზზე დაწერილი კომენტარი იმ ინფორმაციის ნაწილი ხდება, რომელიც ფუნქციის სახელზე მაუსის მიტანისას ჩნდება.
