# ოპერატორები
არითმეტიკული ოპერატორები: `+, -, *, /, //, %, **`
შედარების ოპერატორები: `==, !=, <=, >=, <, >`
ლოგიკური ოპერატორები: `not, and, or`

შენიშვნა: თამაშში ყველა რიცხვი მცურავმძიმიანია, ამიტომ ყველა არითმეტიკული ოპერატორიც მცურავმძიმიან რიცხვებთან მუშაობს.
`//` გაყოფის შემდეგ რიცხვს ქვემოთ ამრგვალებს.

მინიჭების ოპერატორების გამოსაყენებლად „ცვლადები“ უნდა განბლოკო.

## შესავალი
ოპერატორებით შეგიძლია მნიშვნელობები შეადარო, შეცვალო და გააერთიანო. 
არითმეტიკული ოპერატორები `+, -, *, /, //, %, **` რიცხვებზე ჩვეულებრივ მათემატიკურ მოქმედებებს ასრულებს. 
შედარების ოპერატორები `==, !=, <=, >=, <, >` მნიშვნელობებს ადარებს. შედეგი ყოველთვის ან `True`-ა, ან `False`.
ლოგიკური ოპერატორები (მათ ბულის ოპერატორებსაც ეძახიან) `not, and, or` ლოგიკურ მნიშვნელობებს აერთიანებს.
