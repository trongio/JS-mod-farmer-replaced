# სიები

სიას `for` ციკლით შეგიძლია გადაუყვე. შემდეგი მაგალითი სიის ყველა ელემენტს კრებს.

{{codeexample 
{
    "show_image": false,
    "show_code": true,
    "show_inventory": false,
    "show_output": true,
    "collapsing": true,
    "autoplay": false,
    "execution_speed": 1,

    "action_ticks": 200,
    "operation_ticks": 100,
    "seed": 0,

sum = 0
for number in numbers:
	sum += number
print(sum)
}}

სიებს მიმართვითი სემანტიკა აქვს. ეს ნიშნავს, რომ როცა სიას ცვლადს ანიჭებ, ცვლადს იმავე სიის ობიექტი ენიჭება და ასლი არ იქმნება.
თუ ორი ცვლადი ერთსა და იმავე სიაზე მიუთითებს, სიაში შეტანილ ცვლილებებს ორივე დაინახავს.
