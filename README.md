# JS mod for The Farmer Was Replaced

A BepInEx mod that lets you program your drone in JavaScript instead of the
game's Python-like language.

**Status: in development. There is nothing to install yet.**

## Planned approach

JavaScript is parsed into the game's own syntax tree, so tick costs, step-by-step
mode, breakpoints, multi-drone and the builtins should keep working as they do
for Python. Python files should keep working next to JavaScript ones.

Official leaderboard submission will be blocked while the mod is active.

## Not affiliated

This is an unofficial fan project. It does not include any game files or
decompiled game code, so you need your own copy of the game.
